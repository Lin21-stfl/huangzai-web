# 黄磜镇农文旅综合服务平台 · 界面设计方案

> 本目录是基于 `网页布局.docx` 规范重构的完整前端实现。
> 品牌基因延续原站点的**茶绿 + 古镇棕**，在视觉语言、交互模式与可访问性上做整体现代化升级。

---

## 一、设计目标与取舍

| 目标 | 具体做法 |
|---|---|
| **既美观** | OKLCH 色彩体系 · 霞鹜文楷标题字 · 8pt 空间节奏 · 指数缓动 |
| **又易用** | 单滑块价格区间 · 列表 ⇄ 地图记忆偏好 · 筛选状态可视化 · 空状态给退路 |
| **符合用户习惯** | 粘性导航与筛选栏 · 返回不丢筛选 · 44px 触控目标 · 键盘全通 |
| **零门槛运行** | 纯静态 · 无构建步骤 · 无依赖 · 双击即可打开 |

## 三、设计系统

### 3.1 色彩 · OKLCH 感知均匀空间

原站品牌色被反解为 OKLCH 精确等价，再扩展成完整色阶：

| 角色 | 原值 | OKLCH 等价 |
|---|---|---|
| 主色 · 茶绿 | `#5B7A3A` | `oklch(49.5% 0.088 128)` → `--tea-600` |
| 辅色 · 古镇棕 | `#8B6F47` | `oklch(54.5% 0.062 75)` → `--brown-600` |
| 强调 · 价格红 | `#C84A3E` | `oklch(57% 0.165 30)` → `--red-500` |

**色阶**：茶绿 12 级、棕 10 级、红 8 级、暖中性 15 级。

**关键决策 —— 中性色带色相**：所有灰都取 `chroma 0.006 @ hue 75`，让界面在潜意识里与品牌暖调保持一致。纯灰（`#888`、`#CCC`）在本方案中被完全排除。

**红色的克制用法**：`--red-500` 只用于价格与已收藏态，**从不用于主行动号召**。CTA 永远是茶绿，避免与价格争夺注意力。

### 3.2 双层令牌架构

```
第一层（原始层）  --tea-600: oklch(49.5% 0.088 128)      ← 固定不变
        ↓
第二层（语义层）  --action-primary: var(--tea-600)        ← 唯一的引用入口
```

**深色模式只重定义第二层。** 组件代码永远写 `var(--action-primary)`，因此两种主题自动保持一致，不需要任何 `[data-theme]` 分支样式。深色下另将 `--weight-normal` 由 400 降至 380 —— 浅色文字在深底上视觉更重，减轻字重可获得更平衡的观感。

### 3.3 字体

| 用途 | 字体 | 理由 |
|---|---|---|
| 标题 | **霞鹜文楷 TC**（LXGW WenKai） | 楷体骨架自带茶乡与人文气质，中文小标题辨识度远高于黑体 |
| 正文 | **Noto Sans SC** | 屏幕渲染稳定，字重齐全 |
| 数字 | **Archivo** + `tabular-nums` | 价格、评分、里程对齐成列，扫描更快 |

字号采用 **1.25 模数比**（大三度）。仅展示级字号用 `clamp()` 做流式缩放；正文与 UI 字号固定 rem —— 数据密集界面里流式排版会让宽度抖动。

### 3.4 空间与节奏

8pt 网格，另设 4px 半步。正文行高 1.6（16px → 25.6px），这个值同时是全局垂直节奏的基准。

### 3.5 动效

**只用指数缓动**：`--ease-out-quart`（界面反馈）、`--ease-out-expo`（入场）。全线排除弹跳与回弹曲线 —— 这类曲线在长时间停留的旅游站点上会迅速变得聒噪。

全局 `prefers-reduced-motion` 开关：用户若在系统中开启减少动效，轮播自动播放、滚动揭示、图片漂移全部关闭，界面退回纯静态。

## 四、关键交互决策与依据

### 4.1 价格用单滑块，而非两个输入框

规范原文写的是「价格区间」，但实现为**单条上限滑块**。理由：

- 两个 min/max 输入框天然允许「最小值 > 最大值」这类非法状态，需要额外校验与报错
- 单滑块是一个连续手势，用户拖动即见结果，无需思考「我该填多少」
- 黄磜镇住宿总量仅 9 家，用户真正的决策是「我最多愿意花多少」，而非精确区间

滑块右侧实时输出 `¥80 – ¥480`，并用 `--range-fill` 变量驱动轨道填充色，让「已选范围」可视化。

### 4.2 列表 ⇄ 地图切换，且记住偏好

住宿分散在多个村落，位置差异是决策关键，因此提供地图模式。地图切换后状态写入 `localStorage['hz-view-mode']`，用户下次回到页面时保持上次的选择 —— 这是分类信息类站点的常见习惯。

**地图不依赖任何瓦片服务**：用纯 CSS 绘制（网格底纹 + 河流 + 山脊光斑），图钉是真实按钮并携带价格与无障碍标签。点击图钉会滚动到列表中对应条目并高亮两秒。这样既零密钥、可离线，又保留了「比较位置」这一核心价值。

### 4.3 空状态给出退路，而不是死路

筛选过细导致零结果时，空状态：

- 明确解释**为什么**可能是空的（「黄磜镇的住宿总量不大，条件叠加太细容易空手」）
- 提供两个不同性质的出口：放宽条件（自助） / 打电话（人工）
- 并说明「点放宽会清空全部筛选，**你的搜索词会保留**」

第 3 点是刻意的：用户最怕的是辛苦输入的搜索词和一路点选的筛选被一键清零。

### 4.4 筛选状态始终可见

筛选栏下方常驻一行「已选条件」标签，每个标签带独立移除按钮。用户随时知道「现在为什么只看到 3 个结果」，而不必回想自己点过什么。

### 4.5 全站交互约定

| 模式 | 实现 |
|---|---|
| 筛选逻辑 | 组间 AND、组内 OR；`data-tags` 用逗号分隔 |
| 搜索 | 160ms 防抖，匹配 `data-search` 中的关键词 |
| 导航 | 首屏透明 → 滚动后毛玻璃；移动端抽屉带焦点陷阱与 Esc |
| 返回顶部 | 滚动 700px 后淡入 |
| 详情查看 | 体验页用右侧抽屉，避免跳转打断浏览节奏 |
| 攻略目录 | IntersectionObserver 滚动高亮 |
| 主题 | 内联脚本在首次绘制前写入 `data-theme`，杜绝闪烁 |

## 五、可访问性（WCAG 2.1 AA）

- **对比度**：正文 4.5:1、大字与 UI 元素 3:1；占位符文字同样达到 4.5:1（这是很多设计系统漏掉的项）
- **触控目标**：一切可点元素最小 44×44px，含轮播指示点与筛选标签
- **焦点可见**：统一 `:focus-visible` 焦点环，从未被 `outline: none` 移除
- **键盘可达**：轮播支持 ← →、抽屉焦点陷阱、跳转链接直达主内容
- **语义结构**：`<header> <nav> <main> <article> <aside> <footer>` 完整落地；表格带 `<caption>` 与 `scope`；图标一律 `aria-hidden`
- **状态播报**：结果数量变化通过 `aria-live="polite"` 通知读屏
- **图片替代**：所有图片有描述性 `alt`，装饰性元素标 `aria-hidden`

## 六、响应式断点

| 断点 | 变化 |
|---|---|
| ≥1200px | 侧栏 320px；地图模式三栏并列 |
| 1024px | 侧栏收至 290px，瀑布流 3 → 2 列 |
| ≤1024px | 侧栏折叠到内容下方，文章目录移到正文后 |
| ≤900px | 住宿右侧预订栏转为横向通栏 |
| ≤768px | 导航收进抽屉，筛选栏横滑，触底显示移动操作条 |

| ≤560px | 快捷入口两列，详情抽屉占满宽度 |
| ≤720px | 住宿行、攻略行堆叠为纵向卡片 |

## 八、如何查看

直接双击 `index.html` 即可。无需服务器、无需安装、无网络亦可运行（图片除外）。

建议浏览顺序：**首页 → 景点（试筛选）→ 住宿（试列表/地图切换、拖价格滑块）→ 体验（点卡片看抽屉）→ 攻略 → 攻略详情（滚动看目录高亮）**。

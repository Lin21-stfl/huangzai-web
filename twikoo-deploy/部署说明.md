# Twikoo 云函数部署包（CloudBase 基础版1 · 免费）

本文件夹就是 Twikoo 后端云函数的全部代码，已对齐前端 `twikoo@1.6.39`。
两种方式二选一，任选其一即可上线。

---

## 方式一：控制台手动部署（最稳，推荐新手）

1. 腾讯云控制台 → 云开发 CloudBase → **新建环境**
   - 环境名称：随意（如 `huangzai`）
   - **地域：上海（ap-shanghai）** ← 关键，前端没传 region
   - 计费方式：包年包月 → 套餐版本：**基础版 1（0 元免费档）**
   - 应用模板：空模板
2. 环境 → **登录授权** → 启用「匿名登录」
3. 环境 → **安全配置** → WEB 安全域名 添加：`lin21-stfl.github.io`
4. 环境 → **云函数** → 新建云函数
   - 函数名称：`twikoo`（必须叫这个）
   - 创建方式：空白函数
   - 运行环境：**Node.js 16.13**，内存：128MB → 下一步
   - 函数代码框清空 → 粘贴本包 `index.js` 那一行 → 确定
5. 进 `twikoo` 函数详情 → 函数代码 → 文件 → 新建文件 `package.json`
   - 把本包 `package.json` 的内容粘进去 → **保存并安装依赖**
6. 等状态变「正常」→ 左上角悬停环境名复制 **envId**（形如 `cloud1-9gixxxx`，不带 https）

然后把 envId 填进 `../site.config.js` 第 67 行，跑 `bash ../push-github.sh` 推上线。

## 方式二：命令行自动部署（需你提供 API 密钥）

如果你愿意在腾讯云控制台 **访问管理 → API 密钥管理** 生成一对
`SecretId / SecretKey` 发给我，我可以用 CloudBase CLI 把函数自动推上去，
你只需完成方式一里的第 1~3 步（开账号/建免费环境/开匿名登录/加安全域名）。

命令（我本地执行，密钥通过环境变量传入，不写进文件）：
```bash
npm i -g @cloudbase/cli
export TENCENTCLOUD_SECRET_ID=你的SecretId
export TENCENTCLOUD_SECRET_KEY=你的SecretKey
cd twikoo-deploy
# 先把 cloudbaserc.json 里的 envId 占位换成真实 envId
tcb fn deploy twikoo -e 你的envId
```
`installDependency:true` 会在部署时自动安装 `twikoo-func`，无需手动传 node_modules。

> ⚠️ SecretId/SecretKey 拥有你账号的完整权限，给完部署后建议在控制台**删除/禁用**该密钥。

## 版本对齐说明
- 前端 `growth.js` 固定加载 `twikoo@1.6.39` 的浏览器 SDK。
- 本包 `package.json` 后端依赖 `twikoo-func@1.6.39`，前后端版本一致，避免协议不兼容。
- 若部署时提示找不到该版本，去 https://github.com/twikoojs/twikoo/releases 看最新 `twikoo-func` 版本号替换即可。
